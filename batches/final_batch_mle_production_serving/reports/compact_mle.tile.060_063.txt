mle.tile.060_063.s02 Encode and send the JSON request
Send a JSON request body as encoded bytes in urllib.request.Request(url, data=body, headers={"Content-Type": "application/json"}, method="POST"), then read the response through urlopen with a stated timeout.

mle.tile.060_063.s03 Validate decoded request and response contracts
In the order fixture, decode the body before checking required keys, numeric types, permitted bounds and matrix dimensions. Check the decoded response separately for required output keys and one output per request row. A missing key must be rejected before prediction; an included boundary and a value beyond it are different test cases. Serialize the request, send encoded bytes with the JSON header and stated timeout, then decode the response. Parsing, schema acceptance and output correctness are separate assertions.

mle.tile.060_063.s04 Distinguish JSON decoding from schema acceptance
Raw JSON text is not the structured request, and successful JSON decoding is not schema acceptance. A response with the wrong row correspondence still violates the prediction contract.
