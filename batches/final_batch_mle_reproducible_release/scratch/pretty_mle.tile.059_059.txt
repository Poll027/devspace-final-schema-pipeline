
mle.tile.059_059.s01 explainer Submission starts a bounded job
On the existing platform, bind one authorized job to resolved input versions, resource bounds and the expected artifact. Submission is not proof of successful training.
SageMaker CreateTrainingJob specifies TrainingJobName, AlgorithmSpecification, RoleArn, input/output configuration, ResourceConfig and StoppingCondition. Use the supplied TrainingImage, authorized instance count/type and MaxRuntimeInSeconds. Give InputDataConfig version-resolved inputs and OutputDataConfig the output S3 location; the role must be authorized for those resources.
Channels are exposed under /opt/ml/input/data/CHANNEL; write model output under /opt/ml/model for upload. Inspect final job status and artifact location, checking recorded configuration against the intended artifact. Keep dataset snapshot, code/configuration and resulting run/artifact identities in the execution record.
import boto3, json
import time
from datetime import datetime

def json_default(value):
    if isinstance(value, datetime):
        return value.isoformat()
    raise TypeError(f"Unsupported JSON value: {type(value).__name__}")

with open('managed_contract.json', encoding='utf-8') as handle:
    contract = json.load(handle)
# Supply the authorized storage setting; do not assume an unapproved default.
contract['volume_size_gb'] = int(input('Supplied authorized storage setting (GB): '))
storage_client = boto3.client('s3')
# Verify the selected version before creating a controlled immutable input copy.
selected = storage_client.get_object(Bucket=contract['input_bucket'],
    Key=contract['input_key'], VersionId=contract['input_version'])
input_bytes = selected['Body'].read()
import hashlib
assert hashlib.sha256(input_bytes).hexdigest() == contract['dataset_snapshot']['expected_hash']
storage_client.copy_object(Bucket=contract['input_bucket'],
    Key=contract['immutable_key'], CopySource={'Bucket': contract['input_bucket'],
    'Key': contract['input_key'], 'VersionId': contract['input_version']})
resolved_configuration = {
 'TrainingJobName': contract['job_name'],
 'AlgorithmSpecification': {'TrainingImage': contract['image'],
                            'TrainingInputMode': 'File'},
 'RoleArn': contract['role'],
 'InputDataConfig': [{'ChannelName': contract['channel'], 'DataSource': {
   'S3DataSource': {'S3DataType': 'S3Prefix', 'S3DataDistributionType': 'FullyReplicated',
     'S3Uri': 's3://' + contract['input_bucket'] + '/' + contract['immutable_key']}}}],
 'OutputDataConfig': {'S3OutputPath': contract['output_uri']},
 'ResourceConfig': {'InstanceCount': contract['max_instance_count'], 'InstanceType': contract['instance_type'], 'VolumeSizeInGB': contract['volume_size_gb']},
 'StoppingCondition': {'MaxRuntimeInSeconds': contract['max_runtime_seconds']}}
# The supplied container reads contract['channel_path'], writes contract['model_output_path'].
client = boto3.client('sagemaker')
response = client.create_training_job(**resolved_configuration)
# Observe the same submitted job until its status is terminal.
while True:
    description = client.describe_training_job(TrainingJobName=contract['job_name'])
    if description['TrainingJobStatus'] in ('Completed', 'Failed', 'Stopped'):
        break
    time.sleep(5)
failure_reason = description.get('FailureReason')
if description['TrainingJobStatus'] != 'Completed':
    raise ValueError(failure_reason or description['TrainingJobStatus'])
artifact_reference = description['ModelArtifacts']['S3ModelArtifacts']
assert artifact_reference == contract['artifact_uri']
# Parse this verified S3 reference, then retrieve through authorized storage.
from urllib.parse import urlparse
location = urlparse(artifact_reference)
storage_client.download_file(location.netloc, location.path.lstrip('/'), 'downloads/model.tar.gz')
record = {'dataset_snapshot': contract['dataset_snapshot'],
          'code_reference': contract['code_reference'], 'configuration': resolved_configuration,
          'submission': response, 'description': description,
          'retrieved_artifact_reference': artifact_reference}
with open('execution_record.json', 'w', encoding='utf-8') as handle:
    json.dump(record, handle, default=json_default)
with open('execution_record.json', 'r', encoding='utf-8') as handle:
    parsed = json.load(handle)

mle.tile.059_059.s02 explainer Submit, describe and round-trip
Import boto3 and construct boto3.client("sagemaker"). Submit with client.create_training_job(**resolved_configuration). Describe by TrainingJobName and inspect TrainingJobStatus, FailureReason when present, and ModelArtifacts.S3ModelArtifacts. Save structured configuration or records with json.dump and recover them with json.load; JSON text is not a dictionary.
Verify every selected input version before submission. If the API accepts only mutable channel URIs, materialize the selected version at a controlled immutable location; do not invent a version parameter. Retrieve the output with the authorized storage client and verify its reference against the completed job record. Managed training creates job resources and releases them after termination. Confirm terminal status; submission alone does not end compute use.

mle.tile.059_059.s03 explainer Follow one job to its artifact
Resolve the supplied image, job name, role, channels, output location, instance bounds and runtime before submission. Verify selected input versions. When channel URIs cannot select versions, materialize the chosen version at the controlled immutable location. Read channels beneath /opt/ml/input/data and write the model beneath /opt/ml/model. Inspect terminal status, any failure reason and artifact location. Retrieve the artifact with the authorized client and compare its reference with the completed job record. Retain snapshot, code/configuration and run/artifact identities together.
Submission is not completion, and a name is not verified input identity. Resources are released after termination; confirm terminal status before concluding compute use has ended.
