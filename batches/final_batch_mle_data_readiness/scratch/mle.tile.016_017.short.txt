Leakage uses information unavailable at prediction time to build a model and can make held-out performance estimates overly optimistic. Trace rows and fields reaching fit and prediction, then remove held-out or future information from those operations. Separate training and evaluation before fitting preprocessing. On held-out inputs call transform, not fit or fit_transform.
Use assert predicate for valid, boundary and failure fixtures. A false predicate raises AssertionError in ordinary non-optimized execution.

mle.tile.016_017.s06 explainer
Before accepting a delivery-fixture result, state the contract and the checks this rule requires.
Derive prediction features only from information available when the prediction is made. Select available records with [row for row in records if row["available_at"] <= prediction_time]. Changing lookup tables can produce different training and serving values. Use the value at the relevant recorded boundary, not an assumed historical latest value.
Compare the feature on original records and on records augmented with later unavailable observations; assert the earlier feature is unchanged. Apply arithmetic only to time-filtered records. For a sum, initialize total = 0 and accumulate total += record["value"] over the accepted list.
{"type": "data_table", "asset_ref": {"asset_id": "ds.feature_records"}, "caption": "Timestamp-bounded sum records"}
from datetime import datetime

def derive(records, boundary):
    prediction_time = datetime.fromisoformat(boundary)
    dated = [dict(row, available_at=datetime.fromisoformat(row["available_at"])) for row in records]
    accepted = [row for row in dated if row["available_at"] <= prediction_time]
    total = 0
    for record in accepted:
        total += record["value"]
    return accepted, total

original, total = derive(fixture["records"], fixture["prediction_time"])
augmented, later_total = derive(fixture["augmented_records"], fixture["prediction_time"])
assert original == augmented
assert total == later_total
print("boundary:", fixture["prediction_time"])
print("original input, augmented input:", fixture["records"], fixture["augmented_records"])
print("accepted, total, augmented accepted, augmented total:", original, total, augmented, later_total)
