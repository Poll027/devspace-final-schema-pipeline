mle.drift_degradation_distinction
tb1 An input distribution changed, but labels are not yet available. Distinguish evidence about inputs, evidence about the conditional target relationship and measured prediction quality before deciding what the observation supports.
tb2 Input data drift is a change in the observed input distribution relative to its reference; input drift monitoring alone does not measure labeled prediction quality. Concept drift changes the conditional target relationship P(Y|X), that is, the relationship between features and labels; a previously useful model can become less useful as that relationship changes. Observed model quality degradation requires comparing predictions with corresponding ground-truth labels and the declared quality reference.
tb3 Without matched available labels, report the supported distribution or service evidence and the unresolved quality question rather than asserting labeled quality degradation. Input marginals describe P(X), conditional-target evidence describes P(Y|X), and matched-label errors describe observed quality; changing one does not logically establish changes in all three.
tb4 Suppose a production window contains more long-distance orders than the reference. That is evidence about P(X), the input distribution. If matched available labels are absent, record the supported distribution or service observation and the unresolved quality question. Conversely, a conditional target relationship can change in the concept-drift sense even when an input summary is not the evidence that reveals it. tb5 Input drift alone is not labeled quality degradation. Changes in P(X), P(Y|X) and matched-label errors do not logically establish one another.
