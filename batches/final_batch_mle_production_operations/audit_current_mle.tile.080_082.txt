mle.tile.080_082.s05 Distinguish data drift, concept drift and observed quality degradation
Ask three separate questions: did inputs change, did the feature–label relationship change, and did measured prediction quality worsen? With labels unavailable, input evidence cannot answer all three.
Input data drift is a change in the observed input distribution relative to its reference; input drift monitoring alone does not measure labeled prediction quality. Concept drift changes the conditional target relationship P(Y|X), that is, the relationship between features and labels; a previously useful model can become less useful as that relationship changes. Observed model quality degradation requires comparing predictions with corresponding ground-truth labels and the declared quality reference.
Without matched available labels, report the supported distribution or service evidence and the unresolved quality question rather than asserting labeled quality degradation. Input marginals describe P(X), conditional-target evidence describes P(Y|X), and matched-label errors describe observed quality; changing one does not logically establish changes in all three.
