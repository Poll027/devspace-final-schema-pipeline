# 04 interactions — EVALUATOR
Fresh context. **Solve every interaction blind first** — from the lesson text only, without reading the key — then compare with the key. The deterministic gate already verified keys against the data; you judge what a script can't.

BLOCKING: more than one defensible answer; a key that is wrong or arguable; a question that needs knowledge no earlier step taught; wrong-option feedback that is false or misleading; a hands-on that does not exercise the practice anchor's `success` sentence; a distractor that is actually correct. ADVISORY: option wording, hint quality, difficulty labels, feedback tone.
Canary tile: every interaction. Later chunks: at least a third (no more than about two thirds unless a defect turns up — then go full depth on that chunk).
For `code_exercise` (SQL or Python), a script already ran the solution and every test and checked the syntax against the glossary's allowed/blocked lists. You judge what it can't: could a different, equally correct query or program be marked wrong (does the prompt pin the output columns, their order, the rows to keep; for Python the variable names and printed form the tests read)? Is the starter genuinely incomplete rather than trivially fixable? Does the result satisfy the practice anchor's `success` sentence? Does a hidden test catch the lazy shortcut it was written for? An exercise that only one phrasing of the query passes is BLOCKING. Two things are NOT defects: (1) a missing "hidden test" for a lazy literal (`total = 23`): `grading.hidden_checks` is derived at stage 06 by mutating the data and the starter's top-level variables and is verified there, and `source_contains` is not a test kind, so never propose it; (2) a `success` sentence whose wording is richer than the glossary's `allowed_syntax` permits: the syntax lists win, and a solution that satisfies the sentence with allowed syntax is correct (ADVISORY at most). Example: the anchor says the reassigned name "holds the new value built from the others" but its `blocked_syntax` bans arithmetic, so `total_orders = orders_per_driver` is a CORRECT exercise: report it as ADVISORY, never BLOCKING, and never ask for `*` or a changed anchor sentence. Only compare the exercise to `allowed_syntax`/`blocked_syntax` as copied from the anchor; if the exercise matches them, the wording is not your call.
End with `VERDICT: PASS|FAIL`, then `BLOCKING|ADVISORY <step_id>: problem → exact fix`.
